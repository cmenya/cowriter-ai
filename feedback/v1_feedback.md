# 《为什么前一天晚上做一点，第二天就会轻松很多》迭代记录

文章从 v1 到 final 共经历 4 个版本，以下记录每次改动的原因和用户的具体反馈。

---

## v1 → v2：扩充内容，找回删掉的信息

**问题**：
- v1 在去 AI 味的过程中删掉了原参考文章大量有价值的信息（心理账户详解、尾巴效应机制、控制感分析、精力三档操作步骤）
- 字数只有约 800 字，太短
- 破折号（——）使用过多，用户明确要求全文不超过 2 个

**用户反馈（原话）**：
> 原本给你的文章里其实有很多很有用的信息，但你把它们都删掉了。我希望你在保持原意不变的前提下，去调整和修改它的语气。

**改动**：
- 还原心理账户、尾巴效应、控制感三个核心机制
- 还原精力三档操作步骤（精力不错 / 一般 / 很累）
- 引入两篇参考文章（《给自己24小时》《困扰我15年的拖延症》）补充决策消耗、15分钟门槛、反馈回路等内容
- 全文破折号归零

---

## v2 → v3：突出前额叶概念，做基础排版

**问题**：
- 用户希望"前夜清障 + 前额叶"这个原理更突出，目前只是顺带一提
- 整体排版平，缺乏视觉层次

**用户反馈（原话）**：
> 尤其是两篇参考文章里面提到的这个"前叶清账原理"，我是着重要放到我的这篇文章里面作为扩充的。

**改动**：
- 将前额叶 + 前夜清障单独扩充为一个完整章节
- 加入 H2 小标题结构、关键术语加粗、`---` 分隔线

**注**：用户在 IDE 中直接将标题里的"清账"改为"清障"，更准确（清除障碍，而非清算账目）。

---

## v3 → v4：改标题，加真实学术引用

**问题**：
- 标题"昨晚动了一下，今天突然就轻松了"被用户认为不好听
- 文中"研究发现"等模糊表述不够可信，用户希望有真实来源

**用户反馈（原话）**：
> 我希望你把这篇文章里面提到的一些所谓"研究发现"，能不能去网上找到真正的出处？你不能胡说八道，不要产生幻觉，要确保是真的查到了是由这位教授或研究员发表的内容。

**核查结果**（网络实时查证，非凭记忆）：

| 概念 | 来源 | 状态 |
|------|------|------|
| 心理账户 | Richard Thaler，芝加哥大学，2017年诺贝尔经济学奖 | ✅ 已确认 |
| 决策消耗 | Shai Danziger + Jonathan Levav，以色列法官研究，PNAS 2011 | ✅ 已确认 |
| 前额叶与睡眠 | Matthew Walker，UC Berkeley，*Why We Sleep* | ✅ 已确认 |
| 尾巴效应 / 蔡加尼克效应 | Bluma Zeigarnik，1927年论文 | ✅ 已确认 |
| "15分钟前额叶预热" | 无法找到具体来源 | ❌ 未写入文章 |

**改动**：
- 标题改回接近原文风格：《为什么前一天晚上做一点，第二天就会轻松很多》
- 四位研究者姓名 + 英文原名写入正文
- 删除无出处的"15分钟"说法，改为有据可查的"冷启动爬坡期"表述

---

## v4 → final：结尾调整 + 排版精修，移入 final 文件夹

**用户反馈**：
- 希望把结尾的"就是这么一点事"改成"写在最后"加 2-3 行总结
- 整体排版还有改进空间

**排版改动**：

| 改动点 | 原版 | 最终版 |
|--------|------|--------|
| 标题下方 | 无 | 加斜体导语 + 字数/阅读时间 |
| 法官研究数据 | 埋在段落中 | 提取为 blockquote |
| 精力三档 | 合在一个长句里 | 拆成加粗标签的列表 |
| 个人故事与"写在最后"之间 | 无分隔 | 补 `---` |
| 结尾 | "就是这么一点事。" | "写在最后"+ 2-3行总结 |

---

## 总结：对未来同类文章的参考

1. **改写参考文章时，信息量不能牺牲**：去 AI 味的目标是改语气，不是删内容
2. **破折号要控制**：用户对破折号敏感，全文建议 ≤ 2 个，能用逗号或分号替代就替代
3. **标题风格**：用户偏好"为什么……"的疑问式标题，不喜欢口语化短句标题
4. **学术引用必须查证**：用 WebSearch 实时确认来源，找不到出处的说法直接删除
5. **排版节点**：数据/研究发现用 blockquote，操作步骤用列表，章节用 `---` 分隔
6. **结尾习惯**：用户偏好"写在最后"式收尾，不喜欢悬空的一句话收尾
