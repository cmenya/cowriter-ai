# CoWriter AI — 协同写作系统

AI 辅助写作工作流：将多篇参考文章融合，结合作者风格档案，生成接近作者本人声音的正式稿。

---

## 项目背景

作者是一位在日本的职场妈妈，正在探索用 AI 辅助内容创作的工作流。本项目记录了从"参考文章 → 风格提取 → AI 生成初稿 → 多轮迭代 → 定稿"的完整过程，并沉淀了可复用的作者风格档案。

---

## 目录结构

```
CoWriter AI/
├── articles/          # 参考文章（内容素材来源）
├── my-writing/        # 作者过去的真实文章（10 篇）
│   └── style-dna.md   # 从 10 篇文章中提炼的写作风格档案
├── drafts/            # AI 生成的各版本初稿
│   ├── v1_...         # 第一版（去 AI 味改写）
│   ├── v2_...         # 第二版（扩充字数）
│   ├── v3_...         # 第三版（排版优化）
│   └── v4_...         # 第四版（加入学术引用，当前最终稿）
├── feedback/          # 修改意见
├── final/             # 最终定稿
├── soul.md            # 作者自我定位档案（身份、风格、受众）
├── skills/            # 安装的写作 Skill
└── CLAUDE.md          # 项目工作流说明
```

## 核心文件说明

### `soul.md`
作者的自我定位档案，包含：
- 身份背景（职场妈妈、在日华侨、银行 IT 出身）
- 偏好风格与主题（AI 工具、个人成长、效率方法）
- 能为读者提供的价值
- 目标受众画像

### `my-writing/style-dna.md`
从作者 10 篇真实文章中提炼的写作风格参数，包含：
- 声音气质（坦诚、自嘲、温暖）
- 句式节奏（中短句、括号吐槽、emoji 标点）
- 语言偏好与禁区
- 三种结构模式（叙事流 / 实验记录 / 散文议论）

### `drafts/v4_*.md`
当前最完整的一篇成品文章：《为什么前一天晚上做一点，第二天就会轻松很多》
- 约 2200 中文字
- 引用了 4 位真实研究者（Richard Thaler、Shai Danziger、Matthew Walker、Bluma Zeigarnik）
- 5 个章节，含学术排版

## 给 Manus 的前端开发说明

**目标**：为这套写作工作流制作一个展示用的前端页面（Mini-Hackathon 展示用）。

**建议展示内容**：

1. **工作流可视化**：把"参考文章 → 风格提取 → 生成初稿 → 迭代 → 定稿"的流程做成直观的流程图或步骤展示

2. **文章展示页**：把 `drafts/v4_*.md` 的内容渲染成漂亮的阅读页面，支持 Markdown 渲染

3. **作者档案展示**：把 `soul.md` 的内容做成作者介绍卡片

4. **风格对比**（可选）：展示改写前后的对比（v1 vs v4）

**技术建议**：
- 静态网站即可（无需后端）
- 支持 Markdown 渲染
- 中文排版友好
- 适合 Vercel 部署
